# NVD. | Creative Portfolio

Obsidian cyber-editorial portfolio of Nathanael Valent D., Web Designer & UI/UX Creator.

## Run Locally

**Prerequisites:**  Node.js

1. Install dependencies:
   `npm install --legacy-peer-deps`
2. Run the app:
   `npm run dev`

No Gemini API key or other environment variables are required.
